지역자활센터에서 쓰기

의뢰부터 Gateway · 사업단 · 사후관리까지, 2026년 자활사업 안내의 기한 규칙과 자활 월별 보고(서식 26호) — 지역자활센터 사례관리 담당자를 위한 설명입니다.

처음 설정 — 설치마법사에서 고를 것

  1. 설치본을 받아 풀고 챙김Note.exe 를 켭니다(설치 순서).
  2. 설치마법사 첫 화면 「기관 유형」에서 지역자활센터을 고릅니다. 사례관리 단계 · 관심 표시 · 상담 종류 · 평가 점검 기준이 아래처럼 맞춰집니다.
  3. 기관 이름 → 관리자 비밀번호 → 화면 잠금·평가모드 → 사업 분류 → 복구 열쇠 인쇄까지 약 5분.
  4. 먼저 연습해 보시려면 [설정] → [시범자료 넣기](가공 인물 30명). 끝나면 [시범자료 지우기].

기관 유형은 나중에 [설정]에서 바꿀 수 있습니다.

사례관리 단계

  1. 의뢰·접수
  2. 초기상담
  3. 사정
  4. IAP·ISP
  5. Gateway 종결
  6. 사업단 실행·점검
  7. 평가·종결
  8. 사후관리

단계를 누르면 그 단계 문서를 쓰거나 「해당 없음」(사유 필수)으로 둘 수 있습니다. 빠진 단계는 단계 막대에 표시됩니다.

평가 점검에서 보이는 것

[평가 점검] → 평가 구멍 모아 보기가 빠진 단계 · 기한 지남 · 사후관리 기록 없음 · 선정 결과 없음 · 계획 합의 없음 · 사정 영역 빈칸 · 확정하지 않은 상담기록 · 동의서 미회수 · 고충 처리 기한 지남 · 사전 측정만 있고 사후 없음을 한곳에 모읍니다. 줄을 누르면 그 기록으로 갑니다.

기준2026 자활사업 안내 — 지표 번호 대신 서식·기한 근거로 점검
자활 월별 보고메뉴에 「자활 월별 보고」가 더 생깁니다. 월을 고르면 그달 참여자 목록 → 조건이행(이행·불이행·최종일·의견)을 적고 서식 26호 모양 표를 인쇄·엑셀·한글 복사합니다. 주민번호·근로일수·임금 칸은 비워 두니 자활정보시스템 값을 손으로 옮기세요.
질적성과지표자활 질적성과지표 37문항이 기본으로 들어 있습니다. 최초 측정 없음 · 종결했는데 종결 측정 없음이 점검에 뜹니다.

하루 쓰는 순서

  1. 홈에서 평가 구멍 · 기한 있는 포스트잇 · 동의서 미회수 · 고충 처리 기한을 먼저 봅니다.
  2. 이용자 — 새 분은 등록하고 동의서 받음을 표시합니다(안 받은 종류만 [🖨 서식 인쇄]).
  3. 새 의뢰 — 이용자 화면에 보장 구분·의뢰일을 넣고 [+ 사례 열기]로 자활사례관리를 엽니다. 초기상담 14일 기한이 바로 잡힙니다.
  4. 상담기록 — [+ 상담기록 쓰기] → 메모를 짧게 쓰고 [정리하기 →] → 고칠 곳만 다듬고 [확정 저장].
  5. 사례관리 — 진행 중 사례의 단계를 이어 씁니다. 기한이 가까운 단계는 D-날짜로 보입니다.
  6. 연계·자원 — 외부 기관에 의뢰·연계한 것을 남깁니다.
  7. 월초 — 자활 월별 보고에서 지난달 조건이행을 적고 서식 26호를 뽑습니다.
  8. 하루 끝 — 백업은 하루 한 번 자동입니다. 주 1회쯤 [설정]의 [지금 백업]으로 USB 에도 한 부 두세요.
