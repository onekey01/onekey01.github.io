챙김 Note — 사용 안내

v3 · 그림 넣은 판 2026-10-13 · 2026-10-07 · 설치본(챙김Note.exe)용

바로 가기: 처음 30분켜기·끄기화면 둘러보기설치마법사비밀번호·복구 열쇠무료 기간·구독 기능AI 문장 제안백업·PC 바꾸기상담기록사례관리평가 점검연계·고충·권익·척도사업 분류·실적·증빙동의서·양식 인쇄자료가 있는 곳

처음 30분 — 이 순서대로 해 보세요

  1. 폴더 두기 — 압축을 푼 폴더를 통째로 두고 쓸 자리에 옮깁니다(예: C:\챙김Note). 「Program Files」 안이나 압축 파일 안에서 바로 켜면 자료를 저장하지 못합니다.
  2. 켜기 — 챙김Note.exe 를 두 번 누릅니다. 「Windows의 PC 보호」 파란 창이 뜨면 [추가 정보] → [실행]. 검은 창이 뜨고 잠시 뒤 브라우저에 화면이 열립니다.
  3. 설치마법사 다섯 화면 — 기관 유형 → 기관·첫 사용자 → 관리자 비밀번호 → 화면 잠금·평가모드 → 사업 분류·실적 세는 법. 끝에 나오는 복구 열쇠는 꼭 인쇄하세요(다시 볼 수 없습니다).
  4. AI 모델은 기다리지 않습니다 — AI 문장 제안에 쓰는 모델(약 2.5GB)을 프로그램이 뒤에서 스스로 받습니다. 받는 동안에도 아래를 그대로 해 보시면 됩니다.
  5. 연습 자료 넣기 — [설정] → 시범자료 → [시범자료 넣기](가공 인물 30명). 연습이 끝나면 [시범자료 지우기]로 시범자료만 지웁니다.
  6. 기록 한 건 써 보기 — [이용자]에서 한 명을 열고 [+ 상담기록 쓰기] → 메모를 평소처럼 짧게 쓰고 [정리하기 →] → 문장을 눌러 다듬고 [확정 저장].
  7. 사례 하나 열어 보기 — 이용자 화면의 [+ 사례 열기] → 단계 막대에서 단계를 눌러 문서를 써 봅니다.
  8. 백업 한 번 — [설정]의 [지금 백업]. 프로그램 폴더 안 backups 폴더를 USB·외장 하드에 폴더째 복사해 두는 습관을 들이세요.
  9. 끄기 — 검은 창을 닫습니다. 다시 켤 때도 챙김Note.exe 를 두 번 누르고, 관리자 비밀번호를 넣습니다.

켜기 · 끄기

  • 켜기: 챙김Note.exe 를 두 번 누르세요. 검은 창이 뜨고, 잠시 뒤 브라우저에 챙김 Note 화면이 열립니다. 검은 창이 프로그램 본체이니 쓰는 동안 닫지 마세요.
  • 끄기: 검은 창을 닫으면 됩니다. 고친 것은 그때그때 저장되어 있습니다.
  • 이미 켜져 있는데 챙김Note.exe 를 또 누르면 새로 켜지 않고 브라우저 화면만 다시 엽니다.
  • 브라우저 주소는 http://localhost:8095 이며, 이 PC 안에서만 열립니다. 화면을 닫았으면 이 주소를 다시 치면 됩니다.
  • 「Windows의 PC 보호」 창은 새로 만든 프로그램에 뜨는 알림입니다. [추가 정보] → [실행]을 누르면 됩니다.

그림은 시범자료(가공 인물)로 켠 챙김 Note 0.2.1 화면입니다.

  • 켤 때마다 관리자 비밀번호를 넣어야 자료가 열립니다. 자료·동의서 스캔본·첨부·백업은 모두 암호화되어 있습니다.
  • 비밀번호를 잊었을 때: 켜는 화면의 [비밀번호를 잊었어요] → 복구 열쇠 넣고 새 비밀번호 정하기.
  • 비밀번호도 잊고 복구 열쇠도 잃으면 자료와 백업을 누구도 열 수 없습니다. 만든 쪽에서도 열어 드릴 수 없습니다.
  • 비밀번호 바꾸기, 복구 열쇠 새로 만들기: [설정] → 관리자 비밀번호 · 복구 열쇠. 새 열쇠를 만들면 예전 종이는 파기하되, 예전 백업은 예전 열쇠(또는 그때 비밀번호)로만 풀립니다.
  • 화면 잠금 번호(4자리)는 자리를 비웠을 때 화면만 가리는 번호로, 관리자 비밀번호와 따로입니다. 자리 비움 5분(설정에서 변경) 또는 [지금 잠그기].

무료 기간 90일 · 구독 기능

1[설정] → 무료 기간 칸

그림은 시범자료(가공 인물)로 켠 챙김 Note 0.2.1 화면입니다.

  • 처음 설정한 날부터 90일 동안은 모든 기능을 쓰실 수 있습니다. 화면 맨 위에 「무료 기간 N일 남음 · 끝나는 날」이 보이고, 14일 아래로 남으면 주황색으로 바뀝니다. [설정] → 무료 기간 칸에서 처음 설정한 날·며칠째·끝나는 날·이번 달 자동 작성 횟수를 볼 수 있습니다.
  • 91일째부터도 기록 쓰기·보기·인쇄·백업은 그대로 됩니다. 아래 다섯 가지와 자동 작성 한 달 21회째부터만 잠깁니다(메뉴에 🔒 표시).
    91일째부터 잠기는 것 (구독 기능)
    평가 구멍 모아 보기 · 연도별 충족표 · 지표별 증빙 · 실적 보고 · 기관 양식 [채우기]
    자동 작성(「정리하기」로 만든 기록)은 한 달 20회까지는 계속 무료, 21회째부터
  • 자동 작성 횟수 세는 법: 「정리하기」로 만든 초안을 확정 저장한 기록 1건 = 1회. 같은 기록을 다시 고쳐도 1회 그대로이고, 직접 쓴 기록은 세지 않습니다. 달이 바뀌면 0부터. 상담기록 화면에 「이번 달 자동 작성 n/20회」가 보입니다.
  • 구독 기능 다시 열기: 받은 여는 글자(CK1- 로 시작하는 긴 글자)를 [설정] → 무료 기간 칸 아래 「구독 기능 열기」에 붙여 넣고 [여는 글자 넣기]. 넣는 즉시 열리고 윗줄이 「구독 기능이 열려 있습니다 — ○○○○-○○-○○ 까지」로 바뀝니다. 인터넷을 쓰지 않습니다. 줄표·빈칸·소문자는 상관없습니다.
  • 무료 기간 안에 여는 글자를 넣으면 받아 두기만 하고, 무료 90일은 줄지 않습니다. 여는 글자를 받을 때 [설정] → 무료 기간 칸의 이 기관 번호(8글자)를 물어볼 수 있습니다.
  • 날짜는 이 PC의 시계로 셉니다. 백업을 되살리면 처음 설정한 날과 기관 번호도 따라옵니다(PC를 바꿔도 이어짐).

AI 문장 제안 · AI 모델 받기

1[설정] → AI 문장 제안 칸 (모델을 아직 받지 않은 PC 의 모습)

그림은 시범자료(가공 인물)로 켠 챙김 Note 0.2.1 화면입니다.

  • 「정리하기」를 누르면 규칙판(자동 작성 도우미)이 공식 기록을 바로 만들어 줍니다. 여기에 더해 AI 문장 제안(보라색)이 뒤에서 한 문장씩 도착합니다. AI 는 이 PC 안에서만 돌고, 기록을 밖으로 보내지 않습니다.
  • AI 모델(약 2.5GB)은 설치본에 들어 있지 않습니다. 처음 설정을 마치면 프로그램이 스스로 받기 시작합니다. 따로 누르실 것이 없습니다. 빠른 인터넷이면 몇 분, 느리면 30분 넘게 걸릴 수 있습니다.
  • 받는 동안에도 규칙판은 바로 씁니다. AI 제안만 다 받은 뒤부터 나옵니다. [설정] → AI 문장 제안 칸에 「모델 받는 중 37% (925 / 2,382MB)」처럼 받은 만큼이 보입니다(2,382MB 는 약 2.5GB 와 같은 크기입니다).
  • 끊겨도 이어서 받습니다. 인터넷이 끊기면 잠시 뒤 다시 해 보고, 프로그램을 껐다 켜도 받은 데부터 이어서 받습니다. 받은 파일이 올려 둔 것과 같은지 확인한 뒤에만 씁니다.
  • 디스크 빈자리가 3GB쯤 필요합니다. 모자라면 받기 전에 멈추고 알립니다.
  • 인터넷이 막힌 PC: 받지 못해도 규칙판은 그대로 씁니다. 다른 PC에서 받은 모델 파일을 프로그램 폴더의 ai\models 폴더에 넣으면 그대로 씁니다.
  • 받지 않으려면 [설정] → AI 문장 제안의 「AI 제안 쓰기」를 끄세요(받던 것도 멈추고, 받은 데까지는 남습니다). 같은 칸에서 CPU 스레드 수도 바꿀 수 있습니다.
  • 모델을 다 받은 뒤 AI 가 처음 켜질 때는 10~30초 준비 시간이 있습니다.
  • 「AI 제안을 켜려면 윈도 파일이 하나 더 필요합니다」가 뜰 때: 그 PC 에 마이크로소프트의 「Visual C++ 재배포 가능 패키지」(무료)가 없어서입니다. [설정] → AI 문장 제안 칸의 「마이크로소프트 받는 곳 열기」를 눌러 표의 X64 줄 것을 받아 깔고, 프로그램을 껐다 켜세요. 기관 PC 에서 설치가 막혀 있으면 전산 담당자에게 그 화면을 보여 주세요. 깔지 않아도 기록 · 자동 작성(규칙판) · 인쇄 · 백업은 그대로 됩니다.

백업 · PC를 바꿀 때

1[설정] → 백업 · 복원

그림은 시범자료(가공 인물)로 켠 챙김 Note 0.2.1 화면입니다.

  • 켤 때마다 하루 한 번 자동 백업합니다. 자동 백업은 최근 10개만 남기고 옛 것부터 지웁니다. [설정]의 [지금 백업]으로 만든 수동 백업은 저절로 지워지지 않습니다.

PC를 바꿀 때

  2. 단계 막대: 기관 유형별 단계(노인 8단계, 장애 개인별 서비스, 자활 Gateway, 기타 기관은 희망이음 표준 10단계)가 보입니다. 단계를 누르면 그 단계 문서를 쓰거나 '해당 없음'(사유 필수)으로 둘 수 있습니다.
    ✓ 기록됨 · 빠짐(뒤 단계는 있는데 이 단계가 없음) · 해당 없음 · 지금
  3. 단계 문서
    • 접수·선정: 기록 + 선정 결과(사례관리 / 단순 의뢰·정보제공 / 거부 종결). 거부 종결을 확정하면 사례가 닫힙니다.
    • 사정: 공통 10영역 + 기관 유형 영역, 요약·우선 욕구, 전달 기록
    • 계획: 11개 항목(우선순위 · 욕구 영역 · 합의된 욕구 · 단기/중기/장기 목표 · 실행과제·기간·목표 횟수 · 수행 주체와 역할 · 이용자 합의 · 달성 기준 · 변경 사유와 사례회의 · 전달 기록). 다시 세울 때는 지난 계획을 불러와 고칩니다.
    • 점검: 계획 항목별 실행 점검(계속/수정/종료) · 평가: 항목별 달성 여부
    • 종결: 종결 사유, 종결요약(규칙판) — 메모를 "사례: …", "9/20 계획: ①… ②…", "점검: ① 달성 …" 처럼 쓰고 [종결요약 만들기], 목표별 달성, 사후관리 계획·일정. 확정하면 사례가 종결되고 사후관리 날짜마다 포스트잇이 붙습니다.
    • 그 밖의 단계: 메모 → [정리하기](규칙판) + 전달 기록
  4. 과정기록: 상담기록 작성기에서 '사례에 연결'과 단계를 고르면 사례 타임라인에 들어가고 그 단계(실행·점검·사후관리)가 채워집니다. 사후관리 상담을 확정하면 사후관리 포스트잇이 하나씩 끝납니다.
  5. 사례회의: 내부 사례회의 · 통합사례회의 · 솔루션위원회 · 동별 사례판정회의 · 외부 전문가 자문 (장애: 지원점검·평가회의). 참석자, 외부 기관과 역할, 상정 사례별 사정·개입 내용과 결정, 슈퍼비전, 자문료, 지역복지 담당자 참여, 결과 전달 기록.
  6. 기한: 자활은 의뢰일부터 초기상담 14일(+7), IAP·ISP 2개월(+1), Gateway 2개월(+1)을 D-날짜로 보여 줍니다. 장애는 마지막 사정 후 6개월에 진전사정.
  7. 이 사례의 평가 점검: 빠진 단계·기한 지남은 늘 보이고, 평가모드를 켜면 선정 결과 없음, 계획 합의 없음, 전달 기록 없음(장애), 비공식 지지체계 역할(사회), 비어 있는 사정 영역, 제출 대상(사회 3개월 이상)까지 보입니다.
  8. 확정한 문서는 지울 수 없고, [수정]으로 고치면 수정 이력에 남습니다(인쇄에는 안 나옴). 계획·사정·종결보고는 [인쇄 미리보기]로 인쇄합니다.

고충·권익 (메뉴 '고충·권익')

  • 고충 대장: 접수일 · 통로 · 제기자(비우면 익명) · 내용 · 담당 직원 · 처리 결과 · 결과 안내일. 처리 기한 = 접수일 + 설정 일수(기본: 노인·사회·자활·기타 15일, 장애 30일 — 이 화면의 [바꾸기]로 새로 받는 건부터 바꿈). 기한이 지나면 빨간 점(D+n), 3일 안이면 '임박'. 홈의 '고충 처리 기한' 칸에도 뜹니다.
  • 권익옹호 사례 탭: 상황접수 → 사정 → 옹호계획 → 계약 → 옹호지원 → 평가 및 종결. 순서대로만 채웁니다. 종결할 때 성과 유형(개선 입증 / 제도·규정 개선 / 유관기관 연계 / 성과 없음)을 고릅니다.
  • 해마다 필요한 회의·교육: 고충 파악 회의 / 권익옹호 내부 회의 / 권익옹호 직원 교육 / 이용자 권익 교육. 연도별 점검표에서 빠진 것에 빨간 점이 붙습니다.

척도·만족도 (메뉴 '척도·만족도' — 탭: 측정 / 짝 점검 / 만족도 조사 / 척도)

  • 측정: 문항을 누르면 합계·평균·백점 환산을 바로 셉니다(역문항 자동). 한 문항이라도 빠지면 점수를 세지 않습니다.
  • 짝 점검: 사전만 있고 사후가 없는 사람, (자활) 최초 측정 없음 · 종결했는데 종결 측정 없음.
  • 만족도 조사: 조사 한 번에 응답 여러 장(이름 없이). 한 장씩 누르거나 여러 줄을 한꺼번에(예: 5,4,5,5,4,5,5). 응답은 지우지 않고 '빼기/되살리기'.
  • 척도: 기본으로 든 것은 장애 이용자 만족도 7문항 · 자활 질적성과지표 37문항 두 가지입니다. 우울·자존감 같은 일반 척도는 기관이 직접 등록합니다(한 줄에 한 문항, 줄 앞에 '(역)'을 쓰면 역문항). 측정한 뒤에는 문항·점수 범위를 바꿀 수 없으니, 바꾸려면 새 척도로 등록하세요.

첨부 (증빙 파일)

연계·의뢰 건 / 외부 회의·네트워크 / 권익옹호 사례 / 해마다 회의·교육 — 네 곳에 파일을 붙일 수 있습니다(기록을 한 번 저장한 뒤). jpg·png·pdf·hwp·hwpx·docx, 한 파일 20MB, 한 건에 10개까지. data\첨부 에 암호화해 두며 백업에 함께 들어갑니다. 지우기는 없고 '사용 안 함'으로 숨깁니다.

사업 분류 · 실적 보고 · 지표별 증빙 · 모의 추출

1실적 보고 — 기간·기록 종류 고르기
2사업 분류마다 실인원·연인원·건수
3지표별 증빙 — 지표 번호마다 한 장
4[설정] → 실적 세는 법

그림은 시범자료(가공 인물)로 켠 챙김 Note 0.2.1 화면입니다.

  • 기록에 사업 붙이기: 상담기록·연계·사례·사례회의 화면 위 '사업' 칸에서 고릅니다(바꾸면 그 칸만 곧바로 저장). 옛 기록은 [설정] → 옛 기록에 사업 한꺼번에 붙이기.
  • 실적 보고(메뉴 '실적 보고' · 구독 기능): 월별/분기별/한 해 · 기록 종류 · 몇 단계까지를 고르면, 사업 분류마다 실인원 · 연인원 · 건수 표가 나옵니다. 맨 아래 '사업 미지정'과 합계 줄. [엑셀로 저장] · [한글에 붙여넣기용 복사] · 인쇄. 위에 지금 세는 법이 글로 보이고 [설정에서 바꾸기]로 갑니다.
    실인원은 서로 다른 이용자 수라서 위 분류의 실인원이 아래 줄 합보다 작을 수 있습니다. 사례회의는 건수에만 들어갑니다.
  • 지표별 증빙(메뉴 '지표별 증빙' · 구독 기능): 지표 번호마다 한 장 — 점검 줄의 숫자·상태, 근거 기록 목록(누르면 그 기록으로), 앱 밖 서류 체크(서류 이름 · 갖춤 · 보관 위치). [이 장 인쇄(PDF)] · [전체 묶음 인쇄(PDF)] · 이름 가리기 · 지난해 서류 목록 가져오기. 기타 기관은 지표 번호가 없어 한 장이 없습니다.
  • 모의 추출(메뉴 '모의 추출'): 연도 · 뽑을 수(기본 5) · 씨앗값을 넣고 [뽑기] — 그해 사례 가운데 무작위로 뽑아 빠진 항목을 보여 줍니다. 같은 씨앗값이면 언제 뽑아도 같은 사례가 나옵니다. 자료는 바꾸지 않습니다.
  • 자활 월별 보고(지역자활센터만): 월을 고르면 그달 참여자 목록. 조건이행(이행·불이행·최종일·의견)을 적고 [서식 26호] 모양 표를 인쇄·엑셀·한글 복사합니다. 주민번호·근로일수·임금 칸은 비워 둡니다(자활정보시스템 값을 손으로 옮기세요).

동의서·양식 인쇄

1[설정] → 동의서·양식 기관 정보
2기관 양식 — 한 번 옮겨 두면 채워서 뽑음

그림은 시범자료(가공 인물)로 켠 챙김 Note 0.2.1 화면입니다.

동의함·동의하지 않음 칸은 프로그램이 미리 체크하지 않습니다. 본인(또는 법정대리인)이 직접 표시하고 서명합니다. 연락처·주소는 인쇄물에 채우지 않습니다.
  1. 한 사람 동의서: 이용자 화면 → 동의서 칸 [🖨 서식 인쇄] — 아직 못 받은(미회수) 종류만 새 창에 뜹니다(모두 받았으면 3종 전부). 만 14세 미만이면 법정대리인 안내가 크게 찍힙니다. 자활센터는 개인정보·민감정보가 서식 11-2호 한 장입니다.
  2. 미회수 전원 한꺼번에: [이용자] → 동의서 미회수 칩 → 옆의 [🖨 미회수 전원 인쇄] → 'N명 · M장' 확인 → 새 창에서 🖨 인쇄.
    • 기본은 이용 중인 이용자만입니다. 종결·중단한 이용자까지 뽑으려면 '이용 중이 아닌 이용자도'를 체크하세요.
    • 인쇄를 마친 뒤 [N명 인쇄함으로 기록]을 누르면 뽑은 동의서마다 '인쇄일=오늘'이 한 번에 적힙니다. 창만 열고 인쇄하지 않았으면 [기록 안 함].
  3. 기관 문구 넣기: [설정] → 동의서·양식 기관 정보 — 기관 대표·주소·보유기간, 그리고 동의서 3종의 안내 문구·거부 권리 문구를 기관 말투로 고칠 수 있습니다. 비우면 원본 문구 그대로입니다.
  4. 기관 양식 등록(서식마법사): [기관 양식] → [+ 기관 양식 등록] → 한글·워드에서 양식을 모두 선택·복사 → 흰 칸에 붙여 넣기 → 채울 자리를 누르고 오른쪽 이름표 단추(이용자·상담·사례·회의·기간·실적·상담목록·기관)를 누릅니다.
    • 표의 한 줄에 상담목록 이름표를 넣으면 기간 안 확정 상담마다 그 줄이 늘어납니다(월 실적 대장). 겹친 표보다는 단순한 표에서 쓰세요.
    • 원본 한글·워드 파일은 프로그램이 건드리지 않습니다. 모르는 이름표는 저장할 때 알려 주고, 채운 서류에는 ⚠ 로 남습니다.
  5. 양식 뽑기([채우기]는 구독 기능): 양식 줄의 [채우기] → 이용자 → (사례·상담기록·회의) → 기간(비우면 이번 달) → [🖨 채워서 새 창으로]에서 인쇄하거나 'PDF로 저장'. 표가 있는 양식은 [📊 엑셀로 받기]로 .xls 파일을 받을 수 있습니다.
    • 고른 이용자와 다른 사람의 사례·상담기록은 섞이지 않게 막습니다. [숨기기]는 목록에서만 빼고 자료는 남깁니다.
