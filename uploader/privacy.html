1. 이 앱은 무엇인가요

「voy87 업로더」는 Voy.87 운영자가 자기 소유의 유튜브 채널에 직접 만든 영상을 올리고, 제목·설명·썸네일·공개 시각을 관리하려고 쓰는 개인용 도구입니다. 일반 사용자에게 제공하는 서비스가 아니며, 운영자 본인 계정으로만 로그인합니다.

2. 어떤 정보를 쓰나요

  • 구글 로그인 허락으로 받은 YouTube 접근 권한(youtube.upload · youtube.force-ssl)
  • 올린 영상의 ID·제목·공개 상태 같은 업로드 기록

이 정보는 운영자 PC 안에만 저장되며, 외부 서버로 보내거나 다른 사람·회사와 나누지 않습니다. 광고나 분석 목적으로 쓰지 않습니다.

3. YouTube API 서비스

이 앱은 YouTube API 서비스를 사용합니다. 앱을 쓰는 것은 YouTube 서비스 약관에 동의하는 것이며, 구글의 정보 처리는 Google 개인정보처리방침을 따릅니다.

4. 권한을 거두려면

구글 계정 → 서드파티 앱 및 서비스에서 「voy87 업로더」의 접근 권한을 언제든 삭제할 수 있습니다. 삭제하면 운영자 PC에 남은 권한 정보도 더는 쓸 수 없게 됩니다.

5. 보관 기간

권한 정보는 운영자가 앱을 쓰는 동안만 보관하며, 쓰지 않게 되면 PC에서 지웁니다. 업로드 기록은 운영자의 작업 기록으로 보관합니다.
