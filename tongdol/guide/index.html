USB 로 집에서 일하기

사무실에서 USB 에 뜨고, 집에서 가져와 일하고, 다음 날 아침 다시 가져오는 순서.

세 안내는 1.27.40 설치 파일에 든 것과 같은 글입니다. 화면의 이름은 모두 시범자료(가공 인물)입니다.

1.27.40 에서 바뀐 것

  • 설정의 백업정보와 「USB 로 오간 자료」에 「USB 로 집에서 일하기 — 그림으로 보기」 단추가 생겼습니다.
  • USB 를 꽂고 켜면 떠야 할 「USB 에 이 PC 에 없는 것이 있습니다」 띠가 안 뜨거나 곧 사라지던 것을 고쳤습니다.
  • 띠가 떠 있는 동안에는 저절로 뜨는 백업이 USB 에 뜨지 않습니다(이 컴퓨터 안에는 뜹니다). 가져오면 다시 USB 에도 뜹니다.
  • USB 에서 가져온 뒤 백업을 「따로 둘 곳」이 저쪽 컴퓨터의 폴더로 바뀌던 것을 고쳤습니다. 이제 컴퓨터마다 정해 둔 곳이 그대로 남습니다.

이미 깔아 쓰시는 곳은 프로그램이 하루 한 번 새 판을 확인해 화면 위 띠로 알려 드립니다. [지금 바꾸기]를 누르면 갈아 끼우고, 자료함은 건드리지 않습니다.

무료 3개월과 구독

무료 기간처음 설정한 날부터 3개월 동안 모든 기능을 무료로 쓰실 수 있습니다.
끝나기 전끝나기 10일 전부터 화면 위에 남은 날을 알려 주는 띠가 나옵니다.
끝나면새로 쓰는 일(대상자·배정·실적·의뢰·메모, 제공인력 휴대폰 연결)이 잠깁니다. 넣어 두신 자료의 보기·출력·설정·백업·USB·새 버전 받기는 그대로 됩니다. 자료는 사라지지 않습니다.

구독하는 법

  1. 신청 — 문의 메일(onekey00a@gmail.com)로 「통돌 Note 구독 신청」과 기관 이름·담당자 연락처를 보내 주세요.
  2. 안내 받기 — 이용료와 내는 방법은 신청하시면 메일로 안내해 드립니다.
  3. 구독 열쇠 받기 — 안내대로 마치시면 기관 전용 구독 열쇠를 메일로 보내 드립니다.
  4. 넣기 — 관리자 계정으로 [설정] → 이 프로그램 → 구독 열쇠 넣기에 받은 열쇠를 붙여 넣습니다(관리자만 할 수 있습니다).
  5. 확인 — 넣는 즉시 잠겼던 기능이 다시 열립니다. 인터넷 연결은 필요 없습니다.

프로그램을 지우려면

통돌 Note 는 C:\통돌Note 폴더 하나에 프로그램과 자료가 모두 있습니다. 윈도의 「앱 및 기능」 목록에는 나오지 않으니, 아래처럼 손으로 지웁니다.

  1. 먼저 백업 — 다시 쓸 가능성이 조금이라도 있으면 C:\통돌Note\data 폴더를 USB 등에 통째로 복사해 두세요. 지우면 되살릴 수 없습니다(만든 쪽에도 자료가 없습니다).
  2. 프로그램 끄기 — 브라우저 창을 닫고, 작업 표시줄의 통돌 Note(검은 창)를 닫습니다.
  3. 폴더 지우기 — 파일 탐색기에서 C:\통돌Note 폴더를 지웁니다. 「다른 프로그램이 쓰고 있다」고 나오면 PC 를 다시 켠 뒤 지웁니다.
  4. 바로가기 지우기 — 바탕화면과 시작 메뉴의 「통돌 Note」를 지웁니다.
  5. 휴지통 비우기 — 개인정보가 든 자료이니 휴지통까지 비워 주세요. 백업해 둔 USB 의 자료도 더 쓰지 않으실 거면 지웁니다.
윈도 예약 작업·시작 프로그램·레지스트리는 따로 남기지 않습니다. 폴더와 바로가기만 지우시면 끝납니다.
